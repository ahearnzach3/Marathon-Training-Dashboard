# 🏃‍♂️ Marathon Training Dashboard

This repository showcases a comprehensive Marathon Training Dashboard built using **Power BI** and **Python**, created as part of my 2024 Annual Fitness Challenge. The goal? To train for and run my first marathon — and complete it in under 4 hours — all while leveraging data to stay accountable, track progress, and optimize training.

As someone passionate about health and data, this project was a perfect opportunity to combine my interests in fitness and analytics. I used Python for backend data cleaning and transformation, and Power BI to build a dynamic and interactive dashboard that visualizes my training journey.

---

## 🔍 Features

### 1. 🧹 Data Cleaning & Processing (Python)
- **`Zip Folder Extraction Script.ipynb`**  
  Extracts Garmin `.zip` files automatically into a local folder for processing

- **`GPX File Conversion for Run Route Data Mapping.ipynb`**  
  Parses Garmin `.gpx` route files and formats them into usable coordinate data for mapping and spatial analysis

- **`2024 Marathon Training PBI Data Wrangling Final.ipynb`**  
  Cleans and aggregates training metrics including distance, pace, heart rate, and elevation into a structured format for Power BI ingestion

### 2. 📊 Interactive Power BI Dashboard
- Visualizes training data including:  
  - Weekly and Monthly Mileage  
  - Heart Rate Zones  
  - Pace Trends  
  - Elevation Gain  
  - Cumulative Training Load

![Dashboard Screenshot](https://github.com/user-attachments/assets/e0e4af02-b198-4bd7-b0f6-b8d0538834c5)

- **Favorite Feature: ARC GIS Map Route Coverage**  
  Allows full geographic visualization of all my training runs in Charlotte, filterable by date

![Route Coverage Map](https://github.com/user-attachments/assets/ff0b0031-54e2-4df6-9523-491043b28b2b)

### 3. 📈 Training Insights
- Tracks improvements in pace and endurance over time
- Helps identify recovery trends and overtraining signals
- Enables personalized analysis for route difficulty, terrain, and conditions

## 🎯 Background & Motivation

At the start of 2024, I had never run more than 4–5 miles in a single session. As part of my **Annual Fitness Challenge**, I committed to completing a marathon in under 4 hours. To stay disciplined, I used a Garmin watch to track every run and built this dashboard to make sense of the data I was collecting.

This project helped me stay consistent, track progress, and extract meaningful trends that informed how I trained each week. It also gave me a creative outlet to blend my technical skills with a personal goal.
